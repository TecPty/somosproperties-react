## 🛠️ Herramientas de Optimización

### Conversión a WebP
```bash
# Usando cwebp (Google)
cwebp -q 80 input.jpg -o output.webp

# Batch conversion
for file in *.jpg; do cwebp -q 80 "$file" -o "${file%.jpg}.webp"; done
```

### Resize con ImageMagick
```bash
# Hero images (1920x1080)
magick input.jpg -resize 1920x1080^ -gravity center -extent 1920x1080 output.jpg

# Gallery images (1200x800)
magick input.jpg -resize 1200x800^ -gravity center -extent 1200x800 output.jpg
```

### Compresión Online
- **TinyPNG** - https://tinypng.com/ (hasta 5MB)
- **Squoosh** - https://squoosh.app/ (Google, WebP specialist)
- **Compressor.io** - https://compressor.io/


## 🎨 Tips de Fotografía Inmobiliaria

### Mejores Prácticas
1. **Iluminación:** Preferir luz natural, evitar flash directo
2. **Ángulos:** Gran angular para capturar espacios amplios
3. **Altura:** Cámara a nivel de ojos (1.5m aprox)
4. **Composición:** Regla de tercios, líneas guía
5. **Preparación:** Espacios limpios, ordenados, bien decorados
6. **Hora:** 10am-2pm (luz natural óptima)
7. **Clima:** Días despejados o parcialmente nublados

### Errores Comunes a Evitar
- ❌ Fotos oscuras o sobreexpuestas
- ❌ Líneas verticales distorsionadas
- ❌ Reflejos en ventanas/espejos
- ❌ Objetos personales visibles
- ❌ Espacios desordenados
- ❌ Ángulos muy bajos o muy altos
- ❌ Imágenes borrosas o desenfocadas
